Архитектура инфраструктуры продакшна

Реальное окружение сервиса vorobevaqa.ru: сетевой контур, изоляция и автоматизация релизов
Linux VDS & Сеть
Ubuntu 24.04 LTS

Настроенный и защищенный выделенный хост: SSH по ed25519-ключам, сетевой экран UFW (порты 80, 443, ограниченный SSH), Fail2ban от брутфорса, мониторинг дисков и ротация логов (logrotate).

Ubuntu UFW Fail2ban systemd
Nginx API Gateway
Reverse Proxy & SSL

Единая точка входа с терминацией SSL (Let's Encrypt, Certbot), HTTP/2, сжатием Gzip и кастомными fallback-страницами ошибок 502/503. Роутинг трафика на контейнеры веб-приложения и микросервисов.

Nginx SSL / TLS HTTP/2 Upstream
Docker & Blue-Green
Zero-Downtime CD

Микросервисы в изолированной docker-сети с жесткими лимитами памяти (cgroups). Zero-downtime скрипт deploy.sh: подъем параллельного инстанса, валидация через in-binary healthcheck и безопасный откат при сбое.

Docker Compose Blue-Green Auto-Rollback Healthchecks
