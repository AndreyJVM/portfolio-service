Как устроен и развернут данный проект на Linux VDS
Linux Хост (VDS)

Ubuntu 24.04 LTS. Настроен UFW firewall (порты 80, 443, ограниченный SSH), Fail2ban, ротация системных логов, мониторинг swap и изоляция процессов.

Ubuntu UFW Fail2ban
Nginx Gateway

Точка входа трафика (Reverse Proxy). Авто-выпуск и продление SSL (Let's Encrypt), Gzip сжатие, маршрутизация микросервисов (/api/*) и кастомная 50x страница.

Nginx SSL / HTTPS HTTP/2
Docker Compose

Изолированная сеть `app-network`. Нативные healthcheck (in-binary для scratch), строгие квоты CPU/RAM (cgroups limits), ротация логов `json-file` (10m) и `no-new-privileges`.

Healthchecks Logrotate Limits
CI/CD & Deploy

GitHub Actions: сборка и пуш образов в Docker Hub. Развертывание на VDS через `scripts/deploy.sh` по схеме Blue-Green с прогревом и автоматическим Rollback при сбое.

GitHub Actions Blue-Green Rollback
