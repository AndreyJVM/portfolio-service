Шаг 1 • Базовый фундамент (Junior → Middle) 7 уроков с квизами

Docker: От архитектуры до Production-практик

Изучать трек

Фундамент прикладной контейнеризации. Вы изучите устройство слоев OverlayFS, избавитесь от тяжелых контейнеров и научитесь настраивать безопасное окружение для коммерческих микросервисов.

Что вы освоите:
  • Стек dockerd → containerd → runc и Copy-on-Write
  • Multi-stage сборка, Google Distroless и Scratch образы (минус 90% размера)
  • Docker Compose v2, сетевые драйверы и изоляция портов СУБД
  • Тома, Bind Mounts и решение ошибки Permission Denied по UID/GID
Production-стандарты:
  • Харденинг: запуск Non-Root, cap_drop: [ALL], Read-Only root FS
  • Сканирование уязвимостей через Trivy в GitHub Actions пайплайнах
  • Тюнинг демона: live-restore: true, пулы подсетей, расшифровка Exit Code 137 (OOM)
  • Мультиплатформенная сборка amd64/arm64 с Docker Buildx и QEMU
Результат: Уверенное владение контейнерами в реальной командной разработке и CI/CD. Открыть уроки трека (1–7) →

Шаг 2 • Enterprise & Security (Middle → Senior) Rootless & Systemd

Podman & Quadlet: Daemonless-контейнеры

Изучать трек

Переход на стандарты Red Hat / Enterprise Linux. Устранение уязвимого root-демона, запуск контейнеров от непривилегированного пользователя и прямая интеграция в systemd.

Что вы освоите:
  • Архитектура без демона: устранение Single Point of Failure (SPOF)
  • Rootless User Namespaces: root внутри контейнера — обычный UID на хосте
  • Настройка диапазонов субидентификаторов в /etc/subuid и /etc/subgid
  • Сетевой стек pasta / slirp4netns для запуска портов без root
Production-стандарты:
  • Генератор **Quadlet**: декларативные .container файлы для systemd
  • Автозапуск, зависимости и управление контейнерами через systemctl --user
  • Поды в Podman (Kubernetes-подобная модель на одном сервере)
  • Полный отказ от Docker Compose в пользу нативных юнитов операционной системы
Результат: Защищенная инфраструктура без единого root-процесса, готовая к строгим аудитам ИБ. Открыть уроки трека →

Шаг 3 • Системная виртуализация (Middle → Senior) 5 уроков с квизами

LXC / Incus: Легковесные системные контейнеры

Изучать трек

Замена тяжелым виртуальным машинам (KVM, QEMU, Proxmox). Вы получаете преимущества полноценной ОС с `systemd` и собственным IP, но со скоростью железа (bare-metal) и потреблением 20 МБ памяти.

Что вы освоите:
  • Архитектура системных контейнеров против Docker и KVM: полноценный PID 1 systemd
  • Хранилища ZFS Storage Pools: мгновенные CoW-клоны за 0.1 секунды, сжатие ZSTD
  • Моментальные снимки (Snapshots), автоматическое расписание и откат
  • Сетевой драйвер macvlan: свой физический MAC и IP в LAN без NAT
Production-стандарты:
  • Профили (Profiles) и Cgroups v2: CPU Pinning для баз данных без сброса кэша L3
  • Автозапуск контейнеров и защита от дискового «I/O шторма» (boot.autostart.delay)
  • Unprivileged режим: изоляция от хоста при взломе root в контейнере
  • Docker-in-LXC (Nesting) и прямой проброс GPU (NVIDIA CUDA)
Результат: Замена виртуалкам для PostgreSQL, ClickHouse и тестовых сред с экономией 80% RAM хоста. Открыть уроки трека (1–5) →

Шаг 4 • Архитектура ядра (Senior / Staff) Низкоуровневая изоляция

Container Internals: Ядро Linux и изоляция

Изучать трек

Демонтаж магии контейнеров. В Linux нет сущности «контейнер» — есть обычные процессы, ограниченные возможностями ядра. Изучите физику этой изоляции до последнего системного вызова.

Что вы освоите:
  • Анатомия всех 7 Linux Namespaces: PID, Mount, Net, User, UTS, IPC, Cgroup
  • Иерархия Cgroups v2: контроллеры memory.max, cpu.weight, io.max
  • Системные вызовы ядра: clone(2), unshare(2), setns(2)
  • Изоляция файловой системы: почему pivot_root безопаснее chroot
Production-стандарты:
  • Спецификация OCI Runtime Spec: как устроен runc и легковесный C-рантайм crun
  • Написание собственного минималистичного контейнерного рантайма на Go
  • Аудит безопасности: фильтрация системных вызовов через Seccomp и eBPF трейсинг
  • Диагностика контейнеров через procfs (/proc/$PID/ns/) и nsenter
Результат: Уровень экспертного понимания инфраструктуры. Вы сможете решать любые нетривиальные аварии и писать свой тулинг. Открыть уроки трека →
